# Images for the README

These are placeholders referenced from the main README. Add them before publishing:

| File                  | What to show                                                         |
| --------------------- | -------------------------------------------------------------------- |
| `qr.png`              | QR code for your live URL, e.g. `https://<username>.github.io/iman/` |
| `install-ios.png`     | Safari's Share sheet with "Add to Home Screen" highlighted           |
| `install-android.png` | Chrome's "Install app" banner or menu item                           |
| `install-desktop.png` | The install icon in Chrome or Edge's address bar                     |

To make the QR code once your site is live, any QR generator works, for example this
one-off command (not a project dependency):

```bash
npx qrcode -o docs/images/qr.png "https://<username>.github.io/iman/"
```
